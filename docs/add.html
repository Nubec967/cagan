添加服务器

第一步：加入QQ群获取IP

加入 CaGan 官方 QQ 群 728586261，加群时请备注你的游戏 ID，群公告中会公布服务器 IP 地址。

加入官方QQ群

第二步：启动游戏

CaGan 服务器为 Java 基岩互通服，请根据你的游戏版本启动对应的客户端：

Java 版

1.18 ~ 最新版

支持正版账号、离线账号、外置登录（如 LittleSkin）

基岩版

最新正式版

需登录微软账号才能进服

注意：请确保使用正式版客户端，测试版和快照版本均不可进服。若服务端版本有更新，服务器会同步更新。

第三步：添加服务器到列表

获取到服务器 IP 后，按以下步骤将服务器添加到游戏列表中：

Java 版

  1. 启动 Minecraft Java 版，进入游戏主菜单
  2. 点击 "多人游戏"（Multiplayer）
  3. 点击 "添加服务器"（Add Server）
  4. 在"服务器名称"（Server Name）中输入 CaGan（随便写）
  5. 在"服务器地址"（Server Address）中输入从 QQ 群获取到的 IP 地址
  6. 点击 "完成"（Done）保存
  7. 选中该服务器，点击 "加入服务器"（Join Server）即可进入

基岩版

  1. 启动 Minecraft 基岩版，进入游戏主菜单
  2. 点击 "游戏"（Play）
  3. 切换到 "服务器"（Servers）选项卡
  4. 向下滚动，点击 "添加服务器"（Add Server）
  5. 在"服务器名称"（Server Name）中输入 CaGan（随便写）
  6. 在"服务器地址"（Server Address）中输入从 QQ 群获取到的 IP 地址
  7. 在"端口"（Port）中输入服务器对应的端口号（通常为 19132，请以群公告为准）
  8. 点击 "保存"（Save）
  9. 点击服务器卡片即可加入
