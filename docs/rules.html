服务器规则

游玩规则

  1. 不得私自利用服务器漏洞，发现服务器漏洞后应及时向 CaGan JE 服管理组报告。（除原版 Minecraft 游戏存在的特性和漏洞外，其它不合理情况皆可称为服务器漏洞，如刷钱、卡创造等）
  2. 游玩服务器时应发言文明：
    1. 不得讨论任何有涉及色情、恐怖、政治的，违反国家法律法规的或任何未经官方证实的谣言内容。
    2. 不得发布任何未经允许的广告宣传内容。（刻意提及或鼓吹其它服务器、发表有关自己的商业产品的信息等行为都属于广告宣传行为。正常交流过程中少量提及其它服务器或知名商业品牌等行为不属于广告宣传行为。）
    3. 发言应符合社会主义核心价值观，遵守公序良俗。发言应注意场合，适当顾及他人感受。
    4. 使用告示牌、命名、地图等物品时也应遵守该发言规则。
  3. 不得使用外挂作弊客户端或资源包游玩，不得非法修改游戏数据。（矿物透视等资源包禁止使用。仅允许在原版生存服和粘液空岛服使用合理的辅助 mod 游玩，如修改光照、投影、挂机自动操作、灵魂出窍等。禁止飞行、快速挖掘、修改攻击等行为。）
  4. 不得恶意占用服务器资源，造成服务器卡顿。（禁止建造卡服机器等行为。）
  5. 不得盗取他人账号。
  6. 应当自觉保护自己的游戏财产。（如游玩生电服时应使用领地功能保护自己的家园。由于未自觉保护自己游戏财产而造成他人侵害自己利益的，管理员不进行处理。）

群聊规则

  1. 不得讨论任何有涉及色情、恐怖、政治的，违反国家法律法规的或任何未经官方证实的谣言内容。
  2. 不得发布任何未经允许的广告宣传内容。（刻意提及或鼓吹其它服务器、发表有关自己的商业产品的信息等行为都属于广告宣传行为。正常交流过程中少量提及其它服务器或知名商业品牌等行为不属于广告宣传行为。）
  3. 发言应符合社会主义核心价值观，遵守公序良俗。发言应注意场合、适当顾及他人感受。
  4. 不得恶意引入机器人，不得滥用机器人。

其它规则

  1. 严禁一切有关各国法定货币或虚拟货币的交易。
  2. 不得过度散布服务器信息。（不得在其它不当场合如其它服务器群聊宣传本服务器。不得随意散布服务器 IP 地址等信息。）
  3. 本规则的最终解释权归 CaGan JE 服管理组。
