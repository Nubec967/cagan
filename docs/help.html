新玩家快速入门

本文档参考自玩家自制指南

本指南由玩家整理，内容仅供参考。

关于更详细的讲解，请阅读原文。

原文地址：https://blog.danevan.top/posts/help-cagan/

头衔系统

在原版生存服和粘液空岛服内，可以通过指令 /prefix 来自定义玩家头衔。

用法：/prefix &xXXXX

在本服务器内，可以使用颜色代码来自定义头衔颜色，使用 & 替代 §，例如 &b（浅蓝色）等同于 §b。

设置头衔完全免费且不限次数，在任何一个子服务器内设置好的头衔，在传送大厅、原版生存服和粘液空岛服内都能同步显示。

Home 系统

服务器内置了设置家的功能，设置家的数量和次数均无限制。

  • /sethome xxx — 设置名为 xxx 的家
  • /home xxx — 传送到名为 xxx 的家
  • /rmhome xxx 或 /delhome xxx — 删除名为 xxx 的家
  • /renamehome aaa bbb — 将名为 aaa 的家重命名为 bbb

不指定名称时，默认操作名为 home 的家。

传送系统

在原版生存服中，支持玩家间传送：

  • /tpa xxx 或 /tpask xxx — 请求传送到某人
  • /tpahere xxx — 请求某人传送到你这里
  • /tpaccept — 接受传送请求
  • /tpdeny — 拒绝传送请求

一个请求的有效时间为 120 秒，超时自动过期。

切换皮肤

登录服务器后，服务器会自动根据你的 ID 查找对应的正版玩家皮肤。你也可以手动切换皮肤：

  • /skin playerID — 切换到正版玩家 ID 的皮肤，如 /skin Dream
  • /skin url xxx — 从 URL 获取皮肤并应用
  • /skin clear — 清除皮肤，恢复默认

常用功能

  • /back — 死亡后传回死亡地点或上一个 home
  • /tell xxx abc — 向某人私聊
  • /menu 或 Shift+F — 打开箱子菜单
  • [i] — 在聊天框输入可展示手持物品

活死人功能

在原版生存服中，可以使用一系列花样动作：

  • /lay — 原地躺下
  • /sit — 原地坐下
  • /crawl — 原地趴下
  • /spin — 原地转圈

使用这些动作时，其他玩家睡觉可忽略你，实体生物无法察觉你。连按两下 左Shift 可取消状态。

另外，空手右键楼梯或台阶可以直接坐上去。

箱子商店

在原版生存服中，你可以创建箱子商店用于玩家间交易。

  • 创建商店：手持想要出售的物品，左键点击箱子，在聊天框输入单价即可
  • 购买物品：左键箱子商店前的告示牌，在聊天框输入购买数量

世界商店

世界商店可以在箱子菜单中找到，用于直接从服务器购买物品或直接出售物品，相当于服务器银行。

可供交易的物品种类较少，价格较高，建议优先使用箱子商店与玩家交易。

金币系统

在原版生存服中，金币可用于购买物品、创建领地和玩家间支付。

  • 获取金币：出售物品给世界商店
  • 支付金币：/pay xxx 数量 — 向某玩家转账

领地系统

在原版生存服中，服务器内置了领地系统（Residence）。

  • /res create xxx — 创建领地（需先使用木锄选取选区）
  • /res remove xxx — 删除领地
  • /res set — 设置领地公共权限
  • /res pset xxx somebody — 设置某人在领地内的个人权限
  • /res expand ? — 向面前方向扩展领地
  • /res contract ? — 向背后方向收缩领地
  • /res tp xxx — 传送到领地

更多高级功能请查阅服务器内帮助或 Minecraft 插件百科。

MOD 使用

在原版生存服中，一些主流生电 MOD 均可使用，例如：

  • 投影（Litematica）及打印机
  • 灵魂出窍（Tweakeroo、Freecam）
  • 小地图（Xaero、JourneyMap）
  • 方块信息显示（Jade、WTHIT）
  • 一键背包整理

严禁将灵魂出窍用于挖矿，严禁使用矿透 MOD 和外挂客户端。

VIP 和奖励

服务器为公益服务器，VIP 非充值获得。

获得 VIP 的方法：

  • 发布宣传视频到 B 站
  • 在服务器内建造大型建筑
  • 拉新人加入服务器
  • 参加服务器限时活动

VIP 特权：生存模式下飞行（/fly）。
