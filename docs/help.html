新玩家快速入门

本文档参考自玩家自制指南

本指南由玩家整理，内容仅供参考。

关于更详细的讲解，请阅读原文。

原文地址：https://blog.danevan.top/posts/help-cagan/

注册与登录

注册：新玩家首次进服，根据聊天框提示输入：

/register YourPassword YourPassword

注册完成后，会弹出一个箱子页面，需阅读服务器游玩规则并点击绿色玻璃同意。

登录：Java版每次游玩前使用 /login YourPassword 登录。在同一局域网下，24小时内再次进服可免密登录。

基岩版：由于微软账号的唯一性，每次游玩自动登录，无需手动登录。

基岩版玩家在服务器内的 ID 会自动加上 BE_ 前缀，例如：Xbox 代号为 ElofHew，则服务器内 ID 为 BE_ElofHew。

头衔系统

在原版生存服和粘液空岛服内，可以通过指令 /prefix 来自定义玩家头衔。

用法：/prefix &xXXXX

在本服务器内，可以使用颜色代码来自定义头衔颜色，使用 & 替代 §，例如 &b（浅蓝色）等同于 §b。

设置头衔完全免费且不限次数，在任何一个子服务器内设置好的头衔，在传送大厅、原版生存服和粘液空岛服内都能同步显示。

Home 系统

服务器内置了设置家的功能，设置家的数量和次数均无限制。

  • /sethome xxx — 设置名为 xxx 的家
  • /home xxx — 传送到名为 xxx 的家
  • /rmhome xxx 或 /delhome xxx — 删除名为 xxx 的家
  • /renamehome aaa bbb — 将名为 aaa 的家重命名为 bbb

不指定名称时，默认操作名为 home 的家。

传送系统

在原版生存服中，支持玩家间传送：

  • /tpa xxx 或 /tpask xxx — 请求传送到某人
  • /tpahere xxx — 请求某人传送到你这里
  • /tpaccept — 接受传送请求
  • /tpdeny — 拒绝传送请求

一个请求的有效时间为 120 秒，超时自动过期。

切换皮肤

登录服务器后，服务器会自动根据你的 ID 查找对应的正版玩家皮肤。你也可以手动切换皮肤：

  • /skin playerID — 切换到正版玩家 ID 的皮肤，如 /skin Dream
  • /skin url xxx — 从 URL 获取皮肤并应用
  • /skin clear — 清除皮肤，恢复默认

使用 LittleSkin 获取皮肤：

  1. 进入 LittleSkin 官网，登录你的账号
  2. 在皮肤库中，找到一个你喜欢的皮肤
  3. 点击皮肤预览页面的下载按钮
  4. 复制这个皮肤的下载链接（格式为 https://littleskin.cn/raw/皮肤ID）
  5. 在游戏中使用指令 /skin url https://littleskin.cn/raw/皮肤ID
  6. 皮肤应用成功！

常用功能

  • /back — 死亡后传回死亡地点或上一个 home
  • /tell xxx abc — 向某人私聊（服务器后台仍有记录，请注意言行）
  • /menu 或 Shift+F — 打开箱子菜单
  • [i] — 在聊天框输入可展示手持物品
  • 聊天框直接打出玩家完整 ID 可艾特该玩家
  • /co i — 开启查询模式，左键方块可查放置/破坏记录，右键容器可查放入/拿取记录

活死人功能

在原版生存服中，可以使用一系列花样动作：

  • /lay — 原地躺下
  • /sit — 原地坐下
  • /crawl — 原地趴下
  • /spin — 原地转圈

使用这些动作时，其他玩家睡觉可忽略你，实体生物无法察觉你。连按两下 左Shift 可取消状态。

另外，空手右键楼梯或台阶可以直接坐上去。

箱子商店

在原版生存服中，你可以创建箱子商店用于玩家间交易。

  • 创建商店：手持想要出售的物品，左键点击箱子，在聊天框输入单价即可
  • 购买物品：左键箱子商店前的告示牌，在聊天框输入购买数量

世界商店

世界商店可以在箱子菜单中找到，用于直接从服务器购买物品或直接出售物品，相当于服务器银行。

可供交易的物品种类较少，价格较高，建议优先使用箱子商店与玩家交易。

金币系统

在原版生存服中，金币可用于购买物品、创建领地和玩家间支付。

  • 获取金币：出售物品给世界商店
  • 支付金币：/pay xxx 数量 — 向某玩家转账

领地系统

在原版生存服中，服务器内置了领地系统（Residence）。

  • /res create xxx — 创建领地（需先使用木锄选取选区）
  • /res remove xxx — 删除领地
  • /res rename aaa bbb — 将名为 aaa 的领地重命名为 bbb
  • /res give xxx somebody — 将名为 xxx 的领地赠送给某人
  • /res set — 设置领地公共权限（左键启用，右键禁用）
  • /res pset xxx somebody — 设置某人在领地内的个人权限
  • /res padd xxx somebody — 批量添加某人在领地内的常用权限
  • /res pdel xxx somebody — 批量删除某人在领地内的权限
  • /res expand ? — 向面前方向扩展领地
  • /res contract ? — 向背后方向收缩领地
  • /res subzone xxx — 在父领地内创建名为 xxx 的子领地
  • /res message aaa enter xxx — 设置领地进入提示词
  • /res message bbb leave xxx — 设置领地离开提示词
  • /res tpset — 设置当前位置为领地传送点
  • /res tp xxx — 传送到名为 xxx 的领地

费用与赔偿：创建领地每格 0.02 金币，删除领地赔偿总费用的 50%，收缩领地每格 0.01 金币。子领地免费。

冲突规则：不同玩家的领地之间至少间隔 8 格，但同一玩家的不同领地可以紧挨着。两个领地之间不能重叠。

更多高级功能请查阅 Minecraft 插件百科。

MOD 使用

在原版生存服中，以下主流生电 MOD 均可使用：

  • 投影（Litematica）及投影打印机（Litematica Printer）
  • 灵魂出窍（Tweakeroo、Freecam）
  • 小地图（Xaero、JourneyMap）
  • 方块信息显示（Jade、WTHIT）
  • 一键背包整理（Inventory Profile Next）

严禁将灵魂出窍用于挖矿，严禁使用矿透 MOD 和外挂客户端/修改游戏内容的 MOD，违者封号处罚！

其他纯客户端优化 MOD 可以使用。如果拿不准某个 MOD 能不能用，请先咨询服主。

使用 Tweakeroo 时，建议将用不到的功能禁用掉快捷键，以免影响其他玩家。

VIP 和奖励

服务器为公益服务器，VIP 非充值获得。

获得 VIP 的方法：

  • 发布宣传视频到 哔哩哔哩
  • 在服务器内建造大型有观赏价值的建筑（同时奖励金币）
  • 拉新人加入服务器（你和新人均有 VIP 奖励）
  • 参加服务器限时活动（可能同时奖励金币）

VIP 特权：生存模式下飞行（/fly）。

计时标准：按正常时间流逝速度消耗时长。例如 2026年8月8日上午8点获得两天 VIP，则 2026年8月10日上午8点准时到期。
